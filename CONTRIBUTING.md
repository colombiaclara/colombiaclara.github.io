# Contribuir

Use Node 24.19.0 y `npm ci`. Mantenga Spec y Knowledge como checkouts hermanos en los commits de `inputs.lock.json`. Antes de abrir un PR ejecute `npm run check`.

No copie schemas ni datos canónicos a Web. Cambios en elegibilidad, derechos, URLs, CSP, manifests o workflows requieren revisión editorial y de seguridad. Los fixtures son exclusivamente técnicos y nunca se despliegan. No edite `dist/` ni `gh-pages` manualmente.
