# Accesibilidad

Objetivo: WCAG 2.2 AA. Las pruebas automatizadas bloquean ausencia de idioma, landmarks, skip link, encabezado principal, label de búsqueda, live region, caption/headers de tablas, foco visible y reducción de movimiento en superficies representativas.

Matriz automatizada: portada, artículo fixture, Cifras, tema, fuente, búsqueda y 404. La experiencia central se conserva sin JavaScript; evidencia y fuentes están en HTML, mientras `details` funciona de forma nativa.

Antes del primer despliegue se requiere revisión manual de navegación completa por teclado, foco a 200 % de zoom, reflow a 320 px, lectura con NVDA/VoiceOver, contraste de todos los estados, orden de lectura y experiencia de impresión. Una suite automatizada verde no se declara como conformidad total.
